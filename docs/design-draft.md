# 시설 분류 및 개인화 설계 (초안)

목표: 가격과 무관하게, 사용자 개인의 생활 방식·인식에 맞는 "살기 좋은 곳"을 찾아주는 시스템.

| 영역 | 핵심 시설물 |

| 교통 | 지하철역, 버스정류장, 광역버스·GTX, 고속도로 IC, 공영주차장 |
| 교육·육아 | 어린이집, 유치원, 초·중·고, 학원가, 도서관, 소아과 |
| 의료 | 종합병원, 응급실, 의원, 약국, 치과 |
| 생활편의 | 대형마트, 편의점, 전통시장, 은행, 주민센터, 세탁소 |
| 자연·여가 | 공원, 하천·산책로, 산, 체육관, 수영장, 문화센터 |
| 안전 | CCTV, 파출소, 소방서, 안심귀갓길, 가로등, 어린이보호구역 |

## 3. 양면 시설 (너무 가까워도 나쁨)
| 시설 | 장점 | 너무 가까울 때 단점 |
|---|---|---|
| 코스트코·대형마트 | 장보기 편리 | 주말 교통체증, 주차 대기 |
| 지하철역 | 출퇴근 | 소음, 유동인구, 취객 |
| 대형병원 | 응급 대응 | 구급차 소음, 주차난 |
| 학교 | 통학 안전 | 등하교 혼잡, 운동장 소음 |
| 대학가·번화가 | 먹거리·상권 | 야간 소음, 쓰레기 |
| 경기장·대형 쇼핑몰 | 여가 | 행사일 교통마비 |
| 고속도로 IC | 이동 | 소음, 매연 |
| 공원 | 녹지 | 행사 소음, 야간 취객 |

처리 방식: 시설별 거리-점수 곡선(종 모양). 예) 코스트코 0~300m 감점, 500m~1.5km 최고점, 3km 이상 하락.

## 4. 생애 단계별 기본 가중치 (예시, + 선호 / − 기피)
| 시설 | 영유아 | 학령기 | 청년 1인 | 중장년 | 노년(70~80대) |
|---|---|---|---|---|---|
| 어린이집·소아과 | ++ | + | 0 | 0 | 0 |
| 학원가 | 0 | ++ | 0 | 0 | − |
| 번화가·술집 | −− | − | + | 0 | −− |
| 지하철·GTX | + | + | ++ | ++ | + |
| 종합병원·응급실 | + | + | 0 | + | ++ |
| 요양병원·복지관 | 0 | 0 | 0 | + | ++ |
| 경로당·노인복지관 | 0 | 0 | 0 | 0 | ++ |
| 공원·산책로 | ++ | + | + | + | ++ |

노년 전용 변수: 경사도, 계단·엘리베이터, 병원 도보 시간, 차 없는 생활 가능 여부, 버스 배차간격.

## 5. 개인 인식 차이 (개인화 레이어)
사용자 온보딩에서 입력받아 기본 가중치 위에 덮어쓴다.

- 이동수단: 자차 / 대중교통 / 도보 / 자전거
- 소음 민감도, 야간 활동 여부
- 통근 허용 시간, 직장·가족 거주지 위치
- 도시형(활기) vs 한적형(조용) 선호
- 고층/저층, 조망·일조 중요도
- 반려동물 유무
- 심리적 거부감: 장례·묘지, 사행·유흥, 종교시설 인접, 복지시설 인접 등
- 가구 구성, 건강 상태, 향후 5~10년 생애 계획

개별 시설 태도 5단계: **필수 / 선호 / 무관 / 기피 / 절대불가**
- 절대불가 = 하드 필터 (후보에서 제외)
- 기피 = 소프트 감점
- 필수 = 반경 내 없으면 제외

## 6. 점수 모델
```
점수(위치, 사용자) = Σ [ 시설 가중치(유형 × 개인 override) × 거리곡선(시설, 거리) × 시간대 혼잡 보정 ]
```
- 시설별 영향 반경 상이 (소각장·공항 수 km, 주유소·장례식장 수백 m)
- 평일/주말/야간 보정
- 결과 화면에 "이 점수가 나온 이유"(가산·감점 상위 요인) 표시
