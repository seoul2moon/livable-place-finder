# livable-place-finder

가격과 무관하게, 개인의 생활 방식과 선호에 맞는 "살기 좋은 곳"을 보여주는 웹 시스템.

## 핵심 아이디어
- 생활 영역 8개(교통·교육·의료·생활편의·자연·안전·환경·기피요인)별 시설 점수화
- 기피시설 / 양면 시설(너무 가까워도 나쁨)을 거리-점수 곡선으로 처리
- 생애 단계별 기본 가중치 + 개인 override(필수/선호/무관/기피/절대불가)
- 결과 화면에 "이 점수가 나온 이유" 표시

## 예정 스택
Next.js (React) · 지도 API(카카오/네이버) · PostgreSQL + PostGIS
